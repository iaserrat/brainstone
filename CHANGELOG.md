# Changelog

## 0.1.0

First public release. The workspace crates share this version.

- Durable prompt acceptance, sessions, lanes, leases, and crash recovery on
  SQLite and PostgreSQL.
- Native and MCP tools, durable approvals, required tool calls, and structured
  outputs.
- Steering, compaction, skills, subagents, memory, and scheduled work.
- Anthropic, Amazon Bedrock, and OpenAI-compatible model adapters.
- OpenTelemetry traces and metrics, with trace IDs for log correlation.
